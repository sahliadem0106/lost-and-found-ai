Lost & Found · asset production

Making the pictures and videos on Higgsfield

Every prompt you need, in the order to use it. Open a step, press Copy, paste it into Higgsfield. Tick the boxes as you go; they're remembered in this browser.

STEP 0

Before you start

  • Log in at higgsfield.ai and check your credits (top right). Pictures are cheap; each 15-second video costs about 30 credits at 720p.
  • Make a folder on your computer called lost-and-found and save every file there with the exact name this page gives. The names matter: the system reads the camera and clip from them.
  • Higgsfield changes its menus often. If a button has a slightly different name than here, look for the closest match.
STEP 1

Character pictures

6 characters × 3 pictures · image credits only

Go to Image and pick Nano Banana Pro (if you don't have it, use Soul). For each character, make the three pictures in this order:

  1. Reference sheet: aspect ratio 16:9, no reference image. Generate 2–4 versions and keep the best one.
  2. Front photo: aspect ratio 3:4. Upload the sheet you just saved as the reference image, so it's the same person.
  3. Back photo: same as the front, with the sheet as the reference image.

Redo a picture if the clothes colour is wrong, there's text or a logo, or the front/back don't look like the sheet.

STEP 2

Turn each character into an Element

free

An Element keeps a person looking the same in every video. Go to Video, pick Kling 3.0, and open Elements (the @ / element picker next to the prompt).

  1. Create a new Element (character).
  2. Upload the character's three pictures: sheet, front, back.
  3. Name it exactly like the tag, without spaces: @FatherA @MotherA @BoyA @FatherB @MotherB @GirlB. The video prompts use these names.

If your plan has no Elements, skip this step and use Way 2 in each clip below (the full description + the front photos as reference images, on Kling 3.0 Omni).

STEP 4

Check every clip before you keep it

  • The camera doesn't move: no pan, zoom or shake.
  • Clothes keep the same colours for the whole clip and match the pictures.
  • The key moment happens (in A3 the boy really walks out of the store; in A6 the boy never leaves the table).
  • No text, logo or watermark in the picture.
  • Nothing grotesque (melting faces, extra arms). Small flaws are fine.

If a clip fails, regenerate it once. We have 3 spare videos in the budget of 15.
